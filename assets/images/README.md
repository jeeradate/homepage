# assets/images

Placeholder artwork for the portfolio project cards. Each SVG is a lightweight, hand-built UI mockup so the site looks complete before real screenshots are added.

| File | Project card |
| --- | --- |
| `queue-preview.svg` | Real-Time Hospital & Clinic Queue |
| `spapp-preview.svg` | Shopee Seller Notification & Order Monitoring |
| `hotstring-preview.svg` | HotString & Windows Desktop Automation |
| `foodorder-preview.svg` | Food Order & Multi-Role Contact Management |
| `favicon.svg` | Browser tab icon |

## Replacing a placeholder

1. Export a real screenshot or GIF at **1600 × 1000 px** (16:10) or larger.
2. Save it in this folder, e.g. `queue-preview.png` or `queue-preview.gif`.
3. Update the matching `<img src="assets/images/...">` and `alt` text in `index.html`.
4. Keep the image roughly 16:10 so the card crop stays clean. Aim for under ~1.5 MB per file.

See the root `README.md` for full preview, customization, and GitHub Pages deployment notes.
